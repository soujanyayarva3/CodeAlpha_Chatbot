# 🤖 CODEALPHA CHATBOT

## 📌 Overview

AI Knowledge Assistant is an intelligent FAQ chatbot developed as part of the CodeAlpha Artificial Intelligence Internship. The application provides quick and informative answers to questions related to Artificial Intelligence, Machine Learning, Deep Learning, Python, Natural Language Processing, Data Science, and Computer Vision.

The project features a modern dashboard-style interface built with Streamlit, including chat history management, searchable conversations, statistics tracking, and an interactive user experience.

## 🚀 Features

* Modern dashboard-style user interface
* Interactive AI chatbot experience
* Chat history management
* Create new conversations
* Search previous chats
* Delete chat history
* Real-time question and answer system
* Knowledge base covering AI-related topics
* Statistics and insights panel
* User-friendly design with responsive layout
* Session-based conversation tracking

## 🛠️ Technologies Used

* Python
* Streamlit
* Session State Management

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/soujanyayarva3/CodeAlpha_Chatbot.git
```

Navigate to the project directory:

```bash
cd CodeAlpha_Chatbot
```

Install the required libraries:

```bash
python -m pip install -r requirements.txt
```

## ▶️ How to Run

Launch the application using:

```bash
python -m streamlit run chatbot.py
```

The application will automatically open in your default web browser.
