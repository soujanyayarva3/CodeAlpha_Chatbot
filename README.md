# CodeAlpha_Chatbot


This project is a simple FAQ Chatbot developed using Python as part of the CodeAlpha Artificial Intelligence Internship.

## Features

* Answers predefined FAQ questions
* User-friendly command-line interaction
* Continuous chat until user exits

## Technologies Used

* Python

## How to Run

```bash
python chatbot.py
```

## Example Questions

* hello
* what is ai
* what is python
* what is ml
